更新日期：2026-11-08

## 打开方式

在 Mac 上推荐双击 **启动本地版.command**，它会用本机已有的 Python 3 启动仅本机可访问的网页并打开浏览器。使用过程中保持启动窗口开启，工作结束后按 Control+C 关闭。固定使用本地端口 8766，便于同一浏览器恢复快照。若系统阻止启动，请自行检查文件来源和系统提示，不需要关闭系统安全设置。

也可以直接用桌面版 Chrome、Edge 或 Safari 打开 **志愿者分组-完整测试版.html**；不同浏览器对直接打开文件时的本地存储支持不同。实际操作测试采用本机 HTTP 预览地址，未验证每一种浏览器的直接文件打开方式。若直接打开后无法保存阶段，请使用上述本地启动入口。

Excel 解析库已包含在 HTML 中，不需要联网读取名单。启动入口需要电脑已安装 Python 3；本次工作环境已确认具备。

这是可实际导入、分配和导出的功能测试版。真实名单没有预置在文件中。

## 演示模式

点击左下角“演示模式”，或导入页的“体验演示”，即可使用内置虚构名单，无需准备文件。窄屏可从“项目”菜单进入。

- **分组结果**：查看 48 人、4 组、5 个子岗位的示例；42 人已分配，6 人储备，另含 1 条放弃参加记录。可体验搜索、人员详情和 Excel 导出。
- **分配体验**：已完成查重并预设示例组长，从内部人员阶段开始，支持逐阶段分配、拖拽调整或一键完成剩余分配。
- **导入与查重**：预载 6 张虚构表格，逐张确认字段和导入，体验 3 组重复记录的确认与情侣、家属关联。

点击 **“▶ 自动演示”** 可连续播放完整分配：组长与随行家属 → 内部 → 各团体 → 情侣 → 普通 → 储备。姓名标签从左侧待分配移入右侧小组，关联成员一起移动；默认慢速，可选“更慢／正常／快速”。**暂停**会立即停住正在移动的标签，点击**继续**从原位置播放；也可重新播放、结束播放或退出演示。每个阶段自动保存演示历史，完成后返回分组总览。重新播放使用新的虚构分配，不改变真实活动。

顶部可切换场景、重新开始或退出。进入前保存原活动；演示修改和历史仅保留在本次会话，退出或刷新会回到原活动。需要留存演示结果时可导出 Excel 或项目文件。演示使用内置数据，导入自己的名单或打开项目前须退出演示。原活动保存失败时不会进入演示。

## 使用下载的虚构样例测试

1. 在“导入”页点击“测试样例”，下载示例 Excel，再上传。
2. 依次确认小组信息、内部、团体、情侣、家属、普通这六张工作表；小组信息会先显示各项目名额供确认。
3. 点击“确认并继续”。查重时，将重复的“林晓”保留在内部名单。家属“陈夏”按名字关联到“陈宇”。
4. 在任职页，为三个小组分别选择林晓、陈宇、张宁。区长可选周悦，也可以不设。
5. 内部阶段点击“分配未锁定人员”，手动调整后确认。随后逐个确认两个团体，再确认情侣、普通阶段。
6. 样例去重后共 **31 人**，名额 **24 人**；正常完成后应为 **24 人已分组、7 人储备、0 人待分配**。具体分到哪一组可以随随机结果变化。
7. 在“历史”中恢复内部阶段，再恢复后面的快照，检查分配和人数是否对应。
8. 在导出页选择小组和字段，调整列顺序，下载 Excel。填写测试收件邮箱后可预览、生成邮件草稿；不要将测试名单当作真实名单发送。

## 使用自己的名单

- 点击“新建活动”，旧项目先保存到历史；点击顶部活动名称可以改名。
- 下载空白模板填写，或直接上传现有表格。每张表都可以选择类别、表头行和字段对应关系，不自动将整个文件当作团体。
- 团体表内没有团体字段时，填写“默认团体名”。情侣和家属都可以填写“关联志愿者姓名”，重名或未找到人员时人工选择；情侣也兼容配对编号。
- 情侣模板优先填写对方姓名，配对编号可以留空。一方填写对方姓名即可建立双向同组关系，也可以双方互填；两个人仍需各有一条人员记录。姓名与编号指定了不同伴侣时会提示冲突，不会自动合并成三人情侣。
- 摄影、小闪电分别标记“是/否”，可以出现在任何类别中。
- 学号按文本处理。缺少学号的人员可导入，但同名记录需要人工核对。
- 小组信息没有组号列时，组号选择“自动编号”，按每个有效岗位行建立一个小组，从 1 开始；已有小组时从现有最大数字组号继续。空行与合计行不编号，确认导入前可预览。不同项目可以填写相同组号；每个项目保留独立卡片、容量和名单，以“组号 + 项目名称”区分，缺失组号自动补齐。手动添加小组也会自动建议下一个组号。
- 相同组号的项目不会自动合并名额；“7/8”“17/24”等不明确值会要求填写实际名额，不自动猜测。
- 非名单工作表（例如分工、颜色对照、说明）点击“跳过此表”。历史储备表也不会自动参与，若确需加入，应明确选择普通人员类别。
- 某张表需要只导入部分日期或区域时，先在源表副本中保留需要的行，再导入；当前版本按整张选定工作表读取。

## 撤销导入

- 尚在预览的文件：点击“取消此文件”，取消该文件尚未确认的工作表；已经确认的表格不会一并删除。
- 已导入列表：支持“撤销最近导入”“撤销此表”“撤销此文件”。同一文件的多张工作表可以一起撤销。
- 执行前展示移除人数、小组数、退回待分配人数及受影响任职；先保存完整快照，成功后才撤销，不修改原文件。
- 撤销人员来源时，查重合并后仍有其他来源的人员保留；若被撤销的是保留来源，改用剩余来源的原始记录重新核对。
- 撤销小组信息时，只移除该来源建立的小组，相关人员退回待分配。其他名单和小组保留，但查重、任职与后续分配须重新确认。
- 早期测试版已经合并的人员、已经导入的小组可能没有足够的来源标记；遇到无法安全区分的旧数据时，系统会提示从历史恢复，不猜测删除。
- 每次撤销都有前后快照；误撤销可从“历史”恢复。最新版本的项目备份也保留尚未确认的导入预览。

## 人工调整

- 点击姓名多选，Shift 连选；“全选本页”包含本页可见组和右侧可见待分配、储备人员。
- 拖到另一组可移动，拖到另一名字前后可排序；蓝线提示插入位置。
- 也可以使用右侧“移动所选”，不必拖拽。按 Alt + 左/右方向键可调整同组姓名顺序。
- 关系成员会一起选中、移动。绑定和名额不允许时，整个操作不执行。
- 手动移动后默认锁定。“分配未锁定人员”不改变锁定位置。
- 已确认人员要先解锁才能跨组移动；解锁会使相关分配阶段需要重新确认。组长位置须在任职页调整。
- 可以选择另一位置的成员，与其完整绑定组合交换。
- 姓名底色表示来源；📷 摄影、🏃 小闪电、🧑‍🤝‍🧑 情侣/家属，彩旗表示团体。
- 每组始终显示组号、名称、组长、区长。圆环未满为绿色，已满为红色，拖拽、撤销和恢复后实时更新。
- 支持每页 1、2、4、6、8 组或全部，以及卡片/列表视图。

## 新建或清空活动

- 顶部 **“活动 ▾”** 可选择“新建活动”或“清空当前活动”，左侧底部也有直接入口。
- **新建活动**：填写新名称，从空白名单和小组开始。
- **清空当前活动**：保留活动名称，清空人员、来源表、小组、任职、绑定和分配结果。
- 两种操作均需确认；先保存包含待导入表格的完整快照，再切换到空白活动。历史版本不会删除，可恢复旧活动。
- 保存失败时不执行清空；切换不会更改已经下载的 Excel、邮件或备份文件。

## 保存与恢复

每个阶段、每个团体确认后，先保存完整快照再继续。历史版本不会因为回退而被删除；恢复前会备份当前状态。单次调整还可以撤销、重做。

浏览器保存仅属于当前电脑、当前浏览器和当前打开位置。清理网站数据、使用隐私窗口、移动 HTML 或换浏览器可能无法找到原本的本地记录。因此建议每次工作结束点击 **“备份”** 下载 JSON；通过 **“恢复项目”** 载入。备份包含当前状态和历史版本。保存失败时不会自动推进阶段。

## 导出与邮件

- Excel 抬头保留活动、小组、导出时间及任职信息，不显示内部项目修订号。
- 导出为真正的 `.xlsx`，可一个文件多工作表，或每组独立文件打包 ZIP。支持选择、排序列及导出原始字段，储备可单独勾选。
- 小组长出现在本组名单中并标注角色，只计一人，不重复列入名单。小组信息还会单独列出组长及区长名字。
- 邮件只生成 `.eml` 草稿；多组草稿打包 ZIP。每封只包含相应小组的 Excel，附件字段与当前导出选择一致。
- 主题和正文支持 `{小组}`、`{组长}` 占位符。网页不直接发送，也不需要邮箱密码。
- 不同邮箱客户端对 `.eml` 的可编辑草稿支持不同。本版已检查中文正文、附件编码和草稿标志；尚未验证你使用的客户端。若打开为只读邮件，可新建邮件、复制主题正文并附上导出的 Excel 后手动发送。

### 情侣匹配后的类别更新

普通人员一旦成功匹配为某人的伴侣，会自动归入情侣类别，姓名按情侣颜色显示，和伴侣一起分配，不再单独参与普通人员补位。原文件、原始字段和来源记录保留。内部、团体及家属类别不因匹配被覆盖，但仍遵守同组关系。重名待确认、未找到人员或多伴侣冲突时不自动升级。解除全部情侣关系后，仅自动升级过的人员恢复普通类别；原本的情侣类别不自动改变。


## 本次交互更新

- 列名支持包含匹配，例如“Q4. 您的姓名”自动匹配“姓名”，优先精确匹配并避免把拼音、性别或伴侣姓名作为本人姓名。绿色表示已选列，黄色表示未选列，仍可手动更改。
- 导入预览展示全部数据行，支持上下、左右滚动，滚动时固定表头。
- 情侣表的“关联志愿者姓名”和“情侣姓名”都可关联伴侣；同时填写时优先使用“情侣姓名”。摄影／小闪电各自的“是”表示有该标签，“否”表示没有。
- 查重遇到普通记录与团体／情侣记录重合时，优先预选团体／情侣，用户点击确认后才合并。团体与情侣之间没有自动优先规则。
- 关联异常本人、已绑定成员及重名候选标红。查重确认时可选择“暂存并继续”，暂存人员进入“待处理”，不会自动分配或进入储备。可随时点“待处理”修复，修复后回到待分配；仍有异常时不能完成最终确认。
- 人员详情位于储备上方，可展开原始表单完整字段，查看关联成员并进入其编辑页面。
- 待分配区优先展开本阶段／当前团体，其他人员折叠显示。
- 分配速度可选即时、正常、慢速。动画按完整绑定组合移动姓名，人数随进度更新；可暂停、立即完成或取消并还原。一次分配对应一次撤销，确认阶段后仍会保存快照。

更新版本仍是功能测试版。此次额外验证了包含匹配、是／否、重复组号、异常暂存和释放、来源撤销；浏览器验证了完整预览滚动、慢速暂停／取消、立即完成、撤销和异常暂存后进入任职。


## 操作按钮反馈

按钮点击时有轻微按压感。导入、查重保留、阶段确认、保存、自动分配和导出等操作成功后，原按钮内部滑入绿色底色和勾选，完整遮住原文字，约一秒后恢复。按钮尺寸、位置及功能不变；不再使用浮动提示覆盖。失败和仅打开对话框时不会显示成功勾选。开启系统“减少动态效果”时使用静态反馈。

类别先根据工作表名识别，工作表名没有类别信息时再读取文件名。明确识别到情侣、家属、内部、团体、普通或小组信息后自动选择并标绿；名称无明确类别或同时包含多个类别时标黄。仍可手动选择或点击“确认”，不会覆盖已经确认的手动选择。每张工作表分别保留状态。


## 修改已导入工作表

在“已导入”列表中点击对应工作表的“修改导入”。可以重新选择类别、表头行、列对应关系、默认团体名，并点击预览单元格修改内容。点击“预览修改”核对替换影响，再点击“应用修改”。取消修改不会改变已导入的数据，原 Excel 文件也不会改动。

应用修改会按新设置重建这张表的导入记录，并替换旧来源，不会额外追加一份。此表相关的手动人员修改、分配和任职可能需要重新设置；查重及后续分配阶段需要重新确认。已合并人员仍保留其他表的来源，再由查重重新确认。应用前后保存历史快照，任一步保存失败都不替换当前名单。

新导入的表格会保留完整行数据和映射设置。旧版已导入的表格从已保存的原始字段重建，表头从第 1 行开始，无法还原原文件的空行、合并格式及未导入行。界面会提示此限制；若旧记录连原始字段也没有，则需重新上传原文件。


在“确认小组与名额”弹窗中，可直接修改组号、小组名称、总名额和区域，组号允许重复，底部实时显示项目数和总名额。确认后导入修改值；返回或关闭不会改变已导入数据。再次打开“修改导入”时保留已确认的修改。


同组号的多个项目共用同一位组长，选择或清空其中一个项目的组长时会同步同组其他项目。不同组号仍不能共用组长。组长及其绑定成员只编入同组内一个容量足够的项目，人数只计一次；所有项目卡片及导出表头均显示共用组长。


任职页由用户从全部内部人员中手动选择小组长和可选区长，不再读取或展示“是否小组长／报名意向”。同组号子岗位同步组长。重新确认任职保留无关人员的位置与锁定，只调整组长及其绑定成员；容量不足时提示手动调整。旧项目中的原始问卷信息保留。


任职页每行“编辑”旁提供“删除”。只删除该项目，同组号其他项目保留；组内人员及绑定成员回到待分配，不删除人员名单。失去全部任职的独立区长也回到待分配。删除前后保存历史，支持撤销，任职和后续分配须重新确认。

摄影／小闪电已映射列的值包含“报名”（如“已报名”“报名摄影志愿者”）时识别为是；包含“不”“未”“否”“取消”“放弃”等否定或待定表述时优先识别为否。仍兼容原有“是／否”值。仅字段标题包含“报名”不会把整列所有人员标记为是。


顶部“一键完成剩余分配”：完成导入、查重并手动选好组长后，按尚未完成的阶段连续分配，姓名标签从左侧待分配移到右侧各组，关联成员一起移动；普通人员剩余后移入储备。已有分配位置保留，缺少组长时先手选，不自动补选。最终停在总览草案供核对。

- 默认慢速，随时切换“更慢／慢速／正常／快速”；速度调整立即作用于移动中的标签。
- “暂停”会停住正在移动的标签，“继续”从原位置接着播放。
- “立即完成”跳过后续动画，按相同计划完成并保存。
- 每个阶段结束自动保存。“停止并保留进度”还原当前尚未保存的阶段，保留已保存阶段；再次点击“一键完成剩余分配”接着完成。刷新页面也会恢复到最近保存的阶段。
- 保存失败时停止并还原到最近保存的阶段；有无法安置或关联异常人员时保留待处理，完成后在总览检查。
