# 志愿者自动分组 v2.0

中文离线网页工具：导入多来源名单，按团体、情侣和家属关系分配人员，支持人工调整、历史回撤及 Excel 导出。

## 在线使用

访问：https://volunteer-allocator.turtleneck.top

网站与离线包使用相同的功能。名单保存在当前浏览器，不会自动上传或共享；本地版本的数据需先下载项目备份，再在网站中“打开项目”导入。主分支更新并通过测试后，GitHub Pages 自动部署。

## 直接使用

从仓库的 Releases 下载发布包，解压后打开 `志愿者分组-完整测试版.html`。

Mac 推荐双击同目录的 `启动本地版.command`（需要 Python 3），固定使用本机端口 8766，以便同一浏览器持续使用已有历史。更换浏览器或网址会进入不同的本地存储空间；迁移时先下载项目备份，再通过“打开项目”导入。

应用内提供演示模式、虚构测试样例和导入模板。左下角“演示模式”可直接体验分组结果、自动分配及导入查重；“自动演示”支持慢速播放全流程、暂停和继续；退出或刷新恢复原活动。发布包不包含真实志愿者名单。

## 已实现功能

- Excel / CSV 导入、列名自动匹配、导入后修改、按来源撤销。
- 跨表查重、人工确认保留来源，情侣与家属按姓名关联。
- 同组号下独立子岗位，共用组长；手动选择组长，逐阶段自动分配其他人员。
- 默认按来源表先后及表内行顺序分配，绑定组合整体处理。
- 一键完成剩余分配，姓名标签逐批移入各组；支持暂停、继续、四档速度、立即完成及停止保留阶段进度。
- 拖拽和批量调整、容量提示、绑定同伴高亮。
- 上传手工分组结果进行验证评分，检查身份、重复遗漏、名额、绑定及任职；支持全量／局部核对和 Excel 报告。
- 搜索回车定位、放弃参加名单及恢复、阶段快照和项目备份。
- Excel 选择小组与字段、拖拽列排序、自定义列名、多工作表或 ZIP。
- 生成附名单的邮件草稿，交由邮箱客户端发送。

## 本地开发

需要 Node.js 20+ 与 Python 3.10+，无需安装 npm 依赖。

```sh
npm test
npm run build
npm run package
```

构建输出位于 `dist/`，发布 ZIP 位于 `releases/`。也可通过 `python3 -m http.server 8766 --bind 127.0.0.1 --directory dist` 启动网页。

```text
src/       界面模板、样式、交互、分配逻辑
vendor/    随包提供的 Excel 库及许可证
scripts/   构建、测试和打包入口
 tests/    虚构数据回归测试
 docs/     使用说明与项目说明书
 dist/     可直接使用的单文件 HTML 和 Mac 启动入口
```

## 数据与边界

名单在浏览器本地处理，Excel 库已嵌入 HTML，不依赖 CDN。阶段历史保存在当前浏览器的 IndexedDB 中；项目 JSON 备份用于迁移和独立留档。请勿将自己的名单或项目备份提交到仓库。

当前为功能测试版。自动分配草案仍应检查；岗位报名资格尚未建立独立字段，拖拽可用性依据容量、绑定、锁定及任职规则。邮件功能生成草稿，并不直接连接邮件服务器发送。自动测试覆盖逻辑和 Excel 读回，不等同于所有浏览器的视觉与交互验收。
